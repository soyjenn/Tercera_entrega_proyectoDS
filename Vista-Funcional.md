| Caso de Uso | Función que ofrece el sistema |
|-|-|
| Registrar cliente | Permite crear un nuevo cliente almacenando su información personal. |
| Actualizar cliente | Modifica los datos de un cliente existente. |
| Consultar clientes | Muestra la lista de clientes registrados en el sistema. |
| Registrar producto | Permite añadir un nuevo producto al inventario con su precio y stock. |
| Actualizar producto | Modifica la información o stock de un producto. |
| Consultar productos | Permite visualizar todos los productos disponibles en el inventario. |
| Registrar venta | Registra una venta asociando cliente y productos, calcula el total y actualiza el stock. |
| Consultar ventas | Muestra el historial de ventas realizadas con su detalle. |
