|Actor externo|Descripción|Interacción con el sistema|
|-|-|-|
|Cliente|Persona que adquiere productos o servicios.|Consulta productos, realiza compras y recibe comprobante de venta.|
|Vendedor|Usuario encargado de registrar ventas y gestionar clientes/productos.|Crea clientes, gestiona inventario y genera ventas.|
|Administrador|Supervisa la operación general.|Consulta reportes, actualiza precios o stock.|
|Sistema de Facturación|Servicio externo que podría integrarse para emitir facturas electrónicas.|Recibe datos de ventas para generar facturas.|
